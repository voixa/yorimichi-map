# 街歩きガチャ ③「日本地図図鑑」— 要件定義

> 確定日: 2026-07-01 / 手法: `/grillme` / 判断: Obsidian `Decisions/2026-07-01-yorimichi-japan-map-collection.md`
> 対象: `ios-app/www/`（app.js / index.html / style.css） / 前提: ラウンド1〜3完了（色統一・動作修正・ホーム簡素化・金沢/嵐山追加）

## ゴール
「地図×ガチャ×図鑑」を繋ぎ "ポケGO的に地図上で集める" 体験を作る。核＝**図鑑＝引きの絵のイラスト日本地図に、集めた都市のピンが刺さっていく**。

## 日本地図図鑑（本丸）
- **見た目＝イラスト風の可愛い日本列島**（カスタムSVG。実地図ズームアウトは不採用）。「ポップ可愛い上質」トークンと統一。
- **ピン＝都市単位**（金沢/京都/吉祥寺/谷根千…）。都市の緯度経度→SVG座標へ投影して配置。
- **ピン状態**：未着手＝無し/薄い ／ 発見(引いた=`discoveredCourses`)＝途中ピン(グレー/半透明) ／ 制覇(歩いた=`completedCourses`)＝**金ピンで点灯**。
- **ピンタップ→その都市のコース一覧**（現 `showCollection` のシルエットリストを都市別に）。
- 進捗＝「○都市 制覇 / 全△都市」。

## 接続（ガチャ⇔地図⇔図鑑）
- 素地活用：さんぽ地図に既に 未発見`?`カプセル／発見済み絵文字ピン／エリアクラスタ(発見数/総数)。
- **引いた瞬間＝シェア可能**：結果カードから「引いた行き先＋日本地図の到達度」をシェア画像に（既存シェア証明書生成を流用）。
- 新都市を発見したら日本地図にピンが増える導線（結果カード/ホームから「日本地図で見る」）。

## 構造（低リスク）
- 3タブ（ホーム/さんぽ/マイ）維持。**図鑑の主ビューをイラスト日本地図に置換**（都市リストは下位＝ピンタップで展開）。
- さんぽ（本物のLeaflet地図）は実歩行用に現状維持。

## 要検討（Step2で詰める）
1. **イラスト日本SVGの調達**：自作 or パブリックドメイン簡略SVG。lat/lng→SVGの投影（簡易な線形マップ or メルカトル近似）。
2. 都市増加時のピン密度・ラベル衝突。
3. 「制覇」都市判定：都市内で1コース歩けば金 or 全コース制覇で金か。
4. ラウンド1の罠（system-dark色トークン・aria-hidden・キャッシュ）を踏襲。
