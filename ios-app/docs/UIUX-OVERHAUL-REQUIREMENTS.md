# 街歩きガチャ iOS UI/UX 全面オーバーホール — 要件定義

> 確定日: 2026-07-01 / 手法: `/grillme` 言語化 / 判断記録: Obsidian `Decisions/2026-07-01-yorimichi-uiux-overhaul-direction.md`
> 対象コード: `ios-app/www/`（app.js / index.html / style.css / courses.js）= iOS版www（Web版と別管理）

## 0. ゴール
App Store公開済み(build3)の「使い物にならない」を解消する**全面オーバーホール**。
本人申告の不満は4軸すべて該当：①情報過多で迷子 ②見た目が安っぽい/ダサい ③コア体験が刺さらない ④動作不良。

## 1. ターゲット & 利用シーン
- **本命：国内旅行先での街歩き**（京都・金沢など。日本語中心）
- 留学先（ヴェネツィア/欧州）は**別バージョンで後追加** → 今回は多言語化しやすい作りに留める（ハードコード日本語を増やさない）

## 2. コア体験（維持）
**ガチャ→歩く→図鑑**。このループ以外は大胆に削ってよい。

## 3. ビジュアル方針
- **ポップ・可愛い、ただし上質**（今のチープさを払拭）
- 参考の混合：**ポケモンGO系（地図上の収集・位置ゲーム）× Google Maps/Airbnb系（洗練された地図UI・上質な情報設計）× ソシャゲ系のガチャ演出**
- 一言：「**地図主役の収集ゲーム**を、旅アプリの信頼感ある器に乗せ、ガチャの瞬間だけ濃い演出」

## 4. スコープ
1. **機能の大胆な削減・整理**：ホーム約20セクションをコア導線に絞る。削る/隠す候補＝AI提案・TikTok誘導・コース作成・カップル共有・スポット投稿・公開プロフィール 等
2. **ビジュアル刷新**：トークン差し替え方式でポップ上質へ（既存`!important`地獄を避ける）
3. **動作不良の修正**：スマホにフィットしてない／起動遅い／地図が白い／タップ効かない・カクつく
   - ※多くが「まだ未特定」→ **最初の作業＝実機/シミュで観察して特定**
4. **コンテンツ拡張（できれば全部）**：京都・金沢など観光地コース追加（別ワークストリーム）

## 5. 設計上の制約（既知の罠 / Knowledge/yorimichi-redesign-gotchas）
- `[aria-hidden="true"]` は `display:none` される → 装飾は `role="presentation"`
- ホーム簡素化はHTML hidden化では効かない（`setMainTab`がrenderで上書き・`.hidden`トグル289箇所）→ render呼び出し自体を削る
- 地図はdiscover(さんぽ)タブ専用。`body[data-active-tab="home"|"me"] .map-wrap{display:none}` → ホームに本物のLeaflet地図は置けない
- CSSはトークン差し替えで戦う（`:root`6 / `[data-theme="dark"]`44 / `:root:not([data-theme="light"])`55 の3系統）。新規`!important`を増やさない
- 死にHTMLセクションの物理削除は `getElementById`173回 / `.hidden`289箇所が参照＝破壊リスク大。隠す方針で
- 検証：`python3 -m http.server <port> --directory ios-app/www`＋Preview MCP。**ポートを変えて起動＝キャッシュ回避**。絵文字の白黒/空白描画で「壊れ」と誤判定しない（codepoint確認）
